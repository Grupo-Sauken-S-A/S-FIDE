S-FiDE
Sistema de Firma Digital Extendido

Suite Java de código abierto, de Grupo Sauken S.A., para firmar y verificar digitalmente documentos XML y PDF en Argentina bajo la Ley 25.506 de Firma Digital — con tokens criptográficos PKCS#11, certificados PKCS#12, el almacén de certificados de Windows, y especialización completa de comercio exterior ALADI/MERCOSUR (Certificado de Origen Digital y Declaración Jurada de Origen).

Guía de Usuario S-FiDE GUI →
Cómo usar la interfaz gráfica, pantalla por pantalla, con capturas reales de la aplicación — para quien firma y verifica documentos haciendo clic, no por línea de comandos.
Manual Técnico de Integración →
Arquitectura, cada módulo con sus parámetros y errores, mecanismos de firma (PKCS#11/PKCS#12/Windows CSP-KSP), validación de revocación OCSP/CRL, especialización ALADI/MERCOSUR y guía de migración.
Código fuente en GitHub →
Repositorio completo, releases con distribución lista para usar (Windows/Linux), y CHANGELOG detallado de cada versión.
