PKCS12CertificateExtractor - Programa que extrae la clave pública en formato .PEM de Certificado X.509 de un archivo PKCS12

Uso: java -jar PKCS12CertificateExtractor.jar <Archivo PKCS#12> <Contraseña> [-omitir-revocacion true|false]

Opciones:
  -version, -v, --version      Muestra la versión del programa
  -ayuda, -h, --help           Muestra este mensaje de ayuda
  -licencia, --license         Muestra la información de licencia
  -omitir-revocacion true      No consulta el estado de revocación del certificado (por defecto sí se consulta)

Para usar el programa con un certificado PKCS12 (archivos .pfx o .p12):
  java -jar PKCS12CertificateExtractor.jar <Archivo PKCS#12> <Contraseña>

Ejemplo:
   java -jar PKCS12CertificateExtractor.jar c:/carpeta/certificado.p12 "12345678"

Notas:
- La ruta de al certificado digital PKCS12 debe ser la ruta completa al archivo .pfx o .p12
- La contraseña del certificado digital PKCS12 es la PIN de usuario de la firma digital
- El archivo .pem generado contiene únicamente el certificado con su clave pública (no incluye la clave privada).
  Se guarda en la carpeta personal del usuario: <carpeta del usuario>/S-FiDE (por ejemplo, C:\Users\su-usuario\S-FiDE),
  con el nombre tomado del CN del certificado. El programa informa el nombre del archivo y la carpeta donde quedó.
- Además de mostrar los datos del certificado, el programa consulta su estado de revocación (OCSP y, si no responde,
  CRL) y lo informa: VIGENTE, REVOCADO o NO SE PUDO VERIFICAR (por ejemplo, sin conexión a Internet). Es solo
  informativo: no cambia el resultado de la extracción
